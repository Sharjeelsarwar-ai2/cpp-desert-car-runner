Car Racing Game — Console-Based C++ Game

A console-based car racing game developed in C++ as a first-semester programming project.

The game provides an interactive text-based racing experience where the player controls a car, navigates through the road, and avoids obstacles while trying to achieve a high score.

Features

- Console-based racing environment
- Player-controlled car
- Road and lane navigation
- Obstacles
- Collision detection
- Score system
- Increasing game challenge
- Game-over conditions
- Interactive keyboard controls

Technologies Used

- Language: C++
- Interface: Console / Command Line
- Compiler: g++ / MinGW

Gameplay

The player controls a car within a console-based racing environment.

The objective is to navigate the road, avoid obstacles, and continue driving while increasing the score.

Controls

Key| Action
"A"| Move Left
"D"| Move Right
"Q"| Quit Game

How to Run

Clone the repository

git clone https://github.com/YOUR-USERNAME/cpp-car-racing-game.git

Navigate to the project:

cd cpp-car-racing-game

Compile

g++ src/main.cpp -o car-racing-game

Run on Windows

car-racing-game.exe

Run on Linux / macOS

./car-racing-game
